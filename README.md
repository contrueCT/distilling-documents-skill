# distilling-documents

高保真中文文档精炼 Skill：默认把长文整理成一份以后还能查、尽量可以替代原文的通用精炼稿。

## 中文表达层

Skill 已内置针对文档精炼场景适配的自然中文规则，来源于 `KKKKhazix/human-writing` 的部分思路与规则，不要求运行环境另外安装 `human-writing`。详见 `references/human-writing-adapted.md` 与 `THIRD_PARTY_NOTICES.md`。

## Install

把整个 `distilling-documents/` 目录放入支持 Agent Skills 的 skills 目录即可；入口文件为 `SKILL.md`。

`evals/cases.md` 是测试用例，不参与正常输出。
